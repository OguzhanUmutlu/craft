# Craft Roadmap & Phase Tracker (`todo.md`)

This roadmap organizes engineering phases into a strict **Future-Current-Done** lifecycle. Each item is an autonomous phase containing a 5–10 line technical specification outlining its objectives, architecture, prerequisites, and trade-offs. Once completed, phases permanently transition into the Done category.

## Future Phases

Phase 22 delivers automated modpack continuous integration, binary delta patching, and high-speed client file synchronization across federated Craft clusters. Objectives include packaging server-side and client-side modpacks with automated compatibility CI, computing sub-megabyte binary delta patches between modpack versions to eliminate redundant downloads, and serving delta streams over content-addressed HTTP chunk endpoints. Architectural trade-offs prioritize fast block-level binary diffing over whole-archive re-compression. ### Phase 23: Zero-Trust Inter-Server Microsegmentation, eBPF Packet Filtering & WireGuard Overlay Mesh
Phase 23 delivers a zero-trust software-defined network (SDN) overlay mesh and kernel-level packet microsegmentation across distributed multi-cloud server fleets. Objectives include automatically provisioning point-to-point encrypted WireGuard tunnels between proxy ingresses, backend worlds, and storage nodes, applying strict least-privilege L4/L7 packet isolation policies, and inspecting network throughput with zero userspace context switching overhead. Technical approach embeds pure-Rust WireGuard key exchange and dynamic interface configuration in `craft-net`, integrates eBPF/XDP bytecode filters for sub-microsecond packet drops on Linux, and orchestrates mutual TLS certificate rotation via `craft-daemon`. Prerequisites include Phase 6 network security and Phase 11 global edge mesh. Architectural trade-offs prioritize kernel-native packet filtering and WireGuard over heavy user-space OpenVPN or IPsec tunnels. Verification strategy benchmarks line-rate packet processing under simulated DDoS floods, validates network partition containment, and asserts automated mesh reconstitution upon node dropouts.
