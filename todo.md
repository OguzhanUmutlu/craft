# Craft Roadmap & Phase Tracker (`todo.md`)

This roadmap organizes engineering phases into a strict **Future-Current-Done** lifecycle. Each item is an autonomous phase containing a 5–10 line technical specification outlining its objectives, architecture, prerequisites, and trade-offs. Once completed, phases permanently transition into the Done category.

---

## Current Phase

### Phase 29: Autonomous Distributed Consensus Reconfiguration, Multi-Raft Partitioning & Raft Log Compaction
Phase 29 delivers dynamic membership changes, multi-Raft state partitioning, and automated log compaction across federated Craft server clusters. Objectives include supporting online cluster expansion and contraction without downtime, partitioning world regions and fleet services across concurrent independent Raft consensus groups (Multi-Raft) to eliminate single-leader throughput bottlenecks, and truncating append-only WAL logs via streaming state snapshots. Technical approach implements joint consensus membership reconfiguration algorithms in `craft-core`, multi-tenant channel multiplexing in `craft-net`, and asynchronous background snapshot generation with bounded disk watermarks in `craft-daemon`. Prerequisites include Phase 24 Raft clustering, Phase 25 resource quotas, and Phase 26 distributed tracing. Architectural trade-offs prioritize pipelined Raft log replication and non-blocking snapshot streaming over synchronous global cluster locks. Verification strategy asserts zero state divergence during online node addition and removal under synthetic network partition faults, measures snapshot compaction performance, and validates strict zero-emoji data schemas.

### Phase 31: Autonomous eBPF Kernel Observability, Zero-Overhead Syscall Profiling & Deep JVM GC Telemetry
Phase 31 delivers kernel-level non-invasive continuous profiling, zero-overhead syscall interception, and JVM runtime introspection via pure-Rust eBPF probes and Async-Profiler telemetry. Objectives include profiling Minecraft and dedicated server threads directly in kernel space without JVM safepoints or user-space sampling jitter, tracking off-heap socket buffers, file system read/write stalls, and lock contention down to nanosecond resolution, and correlating GC pause spikes with physical hardware memory pressure. Technical approach compiles native eBPF tracepoints and kprobes in `craft-net` and `craft-core`, streams binary trace ring buffers to `craft-daemon`, and aggregates flame graphs and thread state micro-histograms for real-time exposition in ModalX TUI and OpenTelemetry exporters. Prerequisites include Phase 18 Tick Profiling, Phase 23 eBPF Packet Filtering, Phase 26 Distributed Tracing, and Phase 28 DPDK/NUMA Pinning. Architectural trade-offs prioritize in-kernel BPF map aggregations over high-volume raw event ring buffer copying to userspace. Verification strategy measures probe CPU overhead (<0.5% overhead under 20.0 TPS load), validates thread lock contention flame graphs, and enforces strict zero-emoji formatting across all telemetry channels.
